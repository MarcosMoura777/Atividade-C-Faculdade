# Atividades de Programação em C

Este repositório contém exercícios da faculdade
desenvolvidos em linguagem C.

## Conteúdos estudados

- Estruturas condicionais: if e else
- Estruturas de repetição: for, while e do while
- Cálculo de médias e somas
- Contadores e acumuladores
- Validação de dados
- Números primos e fatoriais

## Objetivo

Praticar lógica de programação e desenvolver
algoritmos utilizando a linguagem C.
